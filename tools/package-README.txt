NEW SUPER PAPER BROS. {VERSION}
==============================
Start: open "New Super Paper Bros" (New Super Paper Bros.exe on Windows).

First time only: the game asks for your Super Paper Mario disc image (.iso / .ciso / .wbfs, USA R8PE01 or Europe
R8PP01) and sets itself up from it. Or put the image in this folder before starting. You can delete the image after.

Options: press HOME (F10 on a keyboard, the Guide button on a controller) in the game. Display, sound, controls,
fast-forward, mods, updates and quitting are all there. F11 switches between fullscreen and a window.

Fast-forward: hold F on the keyboard, or click the right stick on a controller (Options > Game sets the speed,
or makes it a toggle).

Mods: Options > Mods > Open the mods folder, put a mod's .zip or folder in it, and start the game again.

Updates: the game checks for a new version when it starts; install it from Options > Game > Update.

Your saves, settings and mods live in engine\UserData. Keep this folder together; it needs nothing else.
